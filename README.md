# Retail Customer Analytics & Segmentation

## Overview
This is a Machine Learning and Data Mining project aimed at identifying meaningful groups of customers based on their historical purchasing behaviour using online retail transaction data. This analysis supports data-driven retail strategies, customer retention, and targeted marketing.

## Business Problem
An online retailer wants to improve sales, customer retention, and product strategy. The business needs a way to group customers based on purchasing behavior so that tailored business strategies can be developed for different customer segments.

## Objective
To transform transaction-level data into customer-level behavioural features and identify groups of customers with similar purchasing behaviour using unsupervised machine learning.
